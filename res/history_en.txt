Script:
=================================
Click the right button of the mouse above the text to choose the command from the menu.

The first word in the line - a command, other words - parameters.

The words consist of symbols 0-9, A-z, А-я, '_'
Symbols * $ of % + - * / > < = (). []: are services, other separators.

In one line there can be only one command.

Case-insensitive.

That goes after '//' considered as the comment.

Example:
wait 5000 // here there is a comment...


Advice:
=================================

To specify a point, guide the cursor on the purpose and press Ctrl+A, and the UO windowPilot should be active!

Do not forget to write End_Repeat, End_IF etc.

At lags put in UO on the button in the end 'waitfortarget', and in script the similar command, then UO and UoPilot will wait, when the cursor will appear.

I recommend putting, for example, Ctrl+1 - meditation. Then in game by pressing Ctrl+1 character will begin to meditate, once again - will cease. That is it is not necessary each time to be switched in UoPilot

Theoretically the names of all functions with the parameters in parentheses can be written together with parentheses: 'set $a Copy(String 1 2)'.

Floating Point in commands 'readmem' and 'writemem' has not been tested. theoretically, should work.

Supported clients 1.26.4a, 1.26.4b, 1.26.4e, 2.0.0, 2.0.0b, 2.0.3, 3.0.0c, 3.0.0g, MU, ML 6.0.7.0, 6.0.12.3, 6.0.12.4, 6.0.13.0, 6.0.14.1, 6.0.14.2, 7.0.4.3-5, 7.0.5.0, 7.0.6.3

added search string in the array. the default looks for an exact match, case-insensitively. 'set %result indexOf ( %arr [noabs] [case] [[startRow [EndRow]] count] (text) )'
    options:
        noabs - if specified, the search for the substring, otherwise, a perfect match, except for the register
        case  - if specified, then the comparison is case sensitive
        count - the maximum number of items found. If > 0, then looking in the direction "from the beginning" if < 0, then looking in the direction "from the end." If not specified, then look for "all". this parameter has precedence in the order of recognition before the start and end position of the search.
searches in columns. returns the address of the found items in the format "row|column/". example: '3|7/3|8/4|7/4|8/'. this format is well aware of the command 'set' to assign an array pack. If nothing is found, returns an empty string.
If the receiver is specified as an integer variable ('set #e indexOf...'), then return only one row number. and 'count' indicates how the entry of the order must be sought. if the element with the specified number is not found, then the result is -1.
    examples:
        set #a indexOf ( %arr case -1 (Test) ) // looking for the number of the last element of the array, which has a value exactly equal to the "Test" (case sensitive)
        set #b indexOf ( %arr (12) ) // looking for the number of the first element of the array, which has a value exactly equal to "12"
        set #c indexOf ( %arr noabs 3 (admin) ) // looking for the number of the third element of the array containing the string "admin"
        set %r indexOf ( %arr case 5 15  2 (Passed) ) // looks at the array elements, with the fifth row on the fifteenth, and returns the address of the cells in the array, containing the first two matches with the exact search string
        set %r indexOf ( %a (14) ) // returns an array of addresses of all cells that match the specified string

--build 12--

Added function to get process priority 'GetProcessPriority ([handle|PID])'. If the handle is not specified, returns the priority of the Uopilot. Returned value:
     '-3' - Error;
     '-2' - Idle priority;                                              
     '-1' - Below normal priority;
      '0' - Normal priority;
      '1' - Above normal priority;
      '2' - High priority;
      '3' - Realtime priority;

Added the function of setting the priority of a process 'SetProcessPriority ([[handle|PID] priority=0])'. If successful, returns "0", otherwise an error code. If the handle is not specified, sets the Uopilot's priority. As a 'priority' uses the same values that returns 'GetProcessPriority'.

In test mode, added the function to set the CPU cores mask for the specified process 'SetProcessAffinityMask ([[handle|PID] mask=0])'. If successful, returns "0", otherwise an error code. If the handle is not specified, sets the Uopilot's priority. As 'mask' the "0" is indicated - all cores, or the sum of the following values:
        1 = CPU 0;
        2 = CPU 1;
        4 = CPU 2;
        8 = CPU 3;
        etc...

--build 16--

Checkbox "Check image capture by handle" moved to the settings \ miscellaneous. Enabled by default.

Added a function to search for values in memory 'findmemory (count value type %result accuracy workwindow)'.
        Returns the number of items found, or an error code.
        Options:
          count - limit quantity, -1 - all;
          value - required value. if the string is not solid, use quotation marks;
          type - the type of the previous argument, as well as in the commands read / write to memory;
          %result - the receiving array;
          accuracy - accuracy of finding a sequence of values;
          workwindow - handle of the working window;
        In 64-bit processes, only the first 32 bits are scanned.
