# UoPilot 2.42

Программа для записи и повторения действий пользователя: мышь, клавиатура,
поиск изображений на экране, собственный язык скриптов и Lua.

## Сборка

Delphi 7. Открыть `uopilot.dpr` и собрать: **Project -> Build**, именно
Build, а не Compile. Compile идёт с ключом `-M` и пересобирает только
изменившиеся модули; порядок работы компилятора при этом другой, и файл
получается не тот.

Настройки лежат в `uopilot.dof` и `uopilot.cfg`. Что в них существенно:

* `synedit` в путях поиска -- редактор скриптов с подсветкой;
* Assertions выключены;
* минимальный размер стека 32768 задаётся директивой `{$MINSTACKSIZE}`
  прямо в `uopilot.dpr`;
* `FastMM4` стоит ПЕРВЫМ в `uses` программы. Он подменяет менеджер памяти,
  и на любом другом месте выдаёт «Память уже была выделена».

Исходники в кодировке **cp1251**. Перекодировка в UTF-8 меняет машинный код
строковых констант, поэтому редактор должен сохранять как есть.

Собирать нужно на системе, где **кодировка ANSI -- 1251** (русская Windows).
Строки текстового `Unit1.dfm` компилятор переводит в UTF-8 по системной
кодировке: на русской системе «Управление» ложится как `D0 A3 D0 BF...`,
на западной каждый байт cp1251 расширяется как Latin-1 и выходит
`C3 93 C3 AF...`. Разница -- 13 694 байта в ресурсе формы.

## Состав

Главное окно и работа

    Unit1.pas        главное окно, настройки, плагины
    Unit2.pas        вспомогательные окна
    uScanThread.pas  поток выполнения: скрипт, поиск на экране, Lua
    uScript.pas      разбор и хранение текста скрипта
    fmFirst_u.pas    заставка
    Unit5.pas        мелкие окна

Ввод и системное

    HotKeyMgr.pas    горячие клавиши
    Keydefs.pas      таблица имён клавиш
    Recorder.pas     запись действий пользователя
    SKey.pas         служба ввода
    sendR.pas        отправка событий ввода
    ProcessAPI.pas   список модулей чужого процесса, 32 и 64 разряда
    ReadMem.pas      чтение и запись чужой памяти
    mySys.pas        системные мелочи

Изображение и поиск

    awMachMask.pas   поиск по маске
    PngGDIP.pas      PNG через GDI+
    GDIPAPI.pas      объявления GDI+
    GDIPOBJ.pas      обёртки GDI+
    geScale.pas      масштабирование
    CRCunit.pas      контрольные суммы

Скрипты и Lua

    lualib.pas       связывание с lua51.dll
    uLuaApi.pas      объявления Lua
    MathEx.pas       вычисления в выражениях скрипта

Прочее

    AttriFont.pas, uAttri.pas       оформление
    LangClipboard.pas               буфер обмена и раскладка
    MyIniFiles.pas                  настройки
    WebLabel.pas, uCircleForm.pas   элементы окна
    LZW_*.pas                       упаковка
    VCLFixes.pas                    правки VCL

Библиотеки: `FastMM4`, `SynEdit` (каталог `synedit`), `PCRE` с
`PerlRegEx` (каталог `pcre`).

Ресурсы: `uopres.res` -- значки, курсор, языковые таблицы, справка, звук
и `lua51.dll`. Исходные файлы для него лежат в `res`.

## Происхождение исходников

Исходники восстановлены из выпущенного `uopilot242.exe` версии 2.42.
Сборка этим проектом даёт исполняемый файл, побайтно совпадающий с
выпущенным (md5 `3357eb2f040d642664ab8802d07d21cc`) -- за вычетом двух
величин, которые из текста программы не выводятся в принципе: меток
времени в дереве ресурсов и метки редакции Delphi в заголовке.
